# Pass 8 — Longitudinal outcomes

This pass turns the first KPI layer into a trend-oriented outcomes page.

## Main changes
- Added a domain-level trajectory classification: Improving, Worsening, Mixed, or Insufficient history.
- Added a consistent Statistics Canada Peterborough CMA Crime Severity Index series for 2021–2025. The separate Peterborough Police Service-area CSI remains visible but is not spliced into the CMA series.
- Extended RGI housing pressure back to 2021: waitlist 1,541 (2021), 1,848 (2022), 1,926 (2023); placements 80 (2022), 78 (2023); average wait 6.0 years (2022), 7.3 years (2023).
- Added a 2018 City transit-ridership historical reference and retained 2023 and 2025 reported totals. The 2025 value remains a lower-bound “3.7M+,” so the UI does not claim an exact recovery-to-peak rate.
- Added 2025 road preservation and reconstruction work as output measures, deliberately separated from road-condition outcomes.
- Removed the previously period-assigned By-Name List value from trend scoring because the source context did not support a clean annual comparison.

## Interpretation discipline
A trajectory grade is only shown where the underlying measures are comparable enough to support one. Infrastructure is intentionally marked “Insufficient history” rather than grading annual maintenance activity as an outcome.
